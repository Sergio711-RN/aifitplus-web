# AIFit+ — сайт aifitplus.com

Лендинг мобильного приложения AIFit+ — подсчёт калорий по фото еды. Проект приложения — `../aifitplus`; его `CLAUDE.md` — источник правды о продукте, цветах и текстах. На сайте: главная с анимированной демонстрацией приложения, политика конфиденциальности, условия использования, страница 404. Только тёмная тема. Три языка: английский (по умолчанию), украинский, русский.

Владелец — ФОП 3-й группы (Украина). Россия — не целевой рынок: приложение там недоступно, юридические тексты пишутся под GDPR, без ссылок на российские законы. Домен `aifitplus.com` зарегистрирован 30.09.2026 у Hosting Ukraine (ukraine.com.ua), там же и хостинг — **виртуальный, тариф «Кращий», без Node.js**. Поэтому сайт — статическая сборка (`output: "export"`), которую отдаёт Apache; всё серверное — в `public/.htaccess`. Настройка хостинга и деплой — `docs/deploy.md`.

## Статус

**Приложение ещё не готово и не опубликовано** (на 1 октября 2026). Аккаунтов разработчика в App Store и Google Play пока нет. **Сайт опубликован** на https://aifitplus.com с 1 октября 2026 (SSL Let's Encrypt на домен с `www` и без, редирект на HTTPS включён в панели), Google Analytics подключён. Это предстартовый лендинг:

- кнопки сторов показывают «Скоро в App Store / Google Play» и не являются ссылками, пока в `STORE_LINKS` (`_lib/content.ts`) стоит `null`. Пока нет релиза, не писать на сайте ничего, что обещает скачать приложение «уже сейчас»;
- распознавание фото в приложении ещё не реализовано (шаг 8 в `../aifitplus/docs/supabase.md`): демо на сайте показывает задуманный сценарий, а политика описывает запланированную обработку — сверять с фактической реализацией перед релизом;
- цифры в демо («Распознано за 2,1 с», серия «12 дней подряд», норма в таймлайне) — иллюстрация, не замеры и не статистика пользователей.

## Команды

- `npm run dev` — dev-сервер на **порту 3002** (порт выбран владельцем, не менять). Для превью — конфигурация `web` в `.claude/launch.json`. Если порт занят процессом `next-server` этого проекта — это уже запущенный dev-сервер: подключаться к нему, а не поднимать второй. После правки `next.config.ts` сервер перезапускается сам. `.htaccess` dev-сервер не читает: `/` ведёт на `/en` (редирект только для dev в `next.config.ts`), выбор языка по cookie и `Accept-Language` и 404 на языке адреса там не проверить.
- `npm run build` — статическая сборка в `out/`: каждая страница, 404 и картинка соцсетей — файл на каждый язык. Если сборка падает на `.next/dev/types/validator.ts` со ссылками на несуществующие маршруты — это устаревшие типы dev-сервера: удалить `.next/dev/types` и собрать снова.
- `npm run preview:static` — собранный `out/` на встроенном в macOS Apache с `.htaccess`, как на хостинге: http://127.0.0.1:8088. Правки `.htaccess` проверять здесь.
- Деплой — только по просьбе владельца. Сейчас владелец выкладывает сам: очищает `www` на хостинге и копирует туда содержимое `out/` вместе со скрытым `.htaccess` (имена файлов в `_next` меняются с каждой сборкой — старые надо убирать). `npm run deploy` (`scripts/deploy.sh`: сборка и `rsync` по SSH, только из закоммиченного состояния) готов, но SSH-ключ и `.env.deploy` ещё не настроены — шаги в `docs/deploy.md`. После выкладки — проверки `curl` из `docs/deploy.md` по живому сайту.
- `npx tsc --noEmit` и `npx eslint app next.config.ts scripts` — перед завершением задачи без ошибок.
- `npm run icons` — пересобрать favicon и иконки из знака приложения (`scripts/build-icons.mjs`, нужен `brew install librsvg`). Результаты (`app/favicon.ico`, `app/icon.svg`, `app/apple-icon.png`, `public/icons/*`) коммитятся, руками не править.

## Стек

- **Next.js 16.3, App Router, статический экспорт.** API отличаются от привычных — перед кодом читать доки в `node_modules/next/dist/docs/`. Уже встречалось: `priority` у `next/image` заменён на `preload`; для 404 при корневом layout в динамическом сегменте нужен `global-not-found` (экспериментальный флаг).
- **Ограничения статики** (сборка падает): нельзя `proxy.ts`, `cookies()` / `headers()`, Server Actions, `redirects`/`rewrites`/`headers` в конфиге (кроме dev-редиректа), оптимизатор картинок Next. Маршрутам с `[lang]` нужен `generateStaticParams`, метаданным-маршрутам (`robots.ts`, `sitemap.ts`, `manifest.ts`) — `dynamic = "force-static"`; `generateImageMetadata` у `opengraph-image` в экспорте не работает. Если понадобится сервер — это бизнес-хостинг, решает владелец.
- **React 19**, **TypeScript**.
- **Tailwind CSS 4**: токены — в `@theme` в `app/globals.css`, конфига `tailwind.config` нет.
- **Motion 13** (импорт из `motion/react`) — анимации; **Lenis** — плавный скролл (`_components/smooth-scroll.tsx`).
- Шрифт — **Commissioner** через `next/font/google` с осями `FLAR` и `VOLM`, как в приложении; кириллица покрывает и украинский.
- Фото блюд — Unsplash (бесплатная лицензия) через `next/image` с загрузчиком `_lib/image-loader.ts`: размер под экран отдаёт сам Unsplash (параметр `w`). Ссылки на фото строить только через `unsplash(id)` из `_lib/photo.ts`.

## Структура

**Маршруты и языки**

- `public/.htaccess` — у каждой страницы есть языковой префикс (`/en`, `/uk`, `/ru`). Адрес без него перенаправляется на язык из cookie `NEXT_LOCALE`, иначе на первый поддерживаемый в `Accept-Language`, иначе на `en`. Там же: адреса без `.html` и без завершающего `/`, 404 по языку адреса, `www` → без `www`, кэш. Название cookie и список языков продублированы там — при изменении `_i18n/config.ts` править и его.
- **На хостинге перед Apache стоит nginx**: файлы с расширением из его списка статики (`.js`, `.css`, `.png`, `.html`, `.txt`…) он отдаёт сам, `.htaccess` на них не действует. Поэтому `/ru.html` открывается с кодом 200 без редиректа (у страницы canonical на `/ru`), а `Cache-Control` из `.htaccess` у `/_next/static/` нет. Кэширование статики в панели **выключено** — так и оставлено; если включать, сначала убрать `txt` и `html` из списка (`docs/deploy.md`, шаг 5). HTTPS принудительно включается в панели, не в `.htaccess` — за прокси правило может зациклиться.
- `app/[lang]/layout.tsx` — корневой layout: `<html lang>`, шрифт, `I18nProvider`, метаданные; `dynamicParams = false` — других языков нет.
- `app/[lang]/page.tsx` — главная, порядок секций: `Nav`, `Hero`, `VelocityMarquee`, `HowItWorks`, `DayTimeline`, `PlanCalculator`, `FinalCta`, `Footer`.
- `app/[lang]/privacy`, `app/[lang]/terms` — юридические страницы на общем макете `_components/legal-page.tsx` (оглавление с подсветкой раздела, прогресс чтения).
- 404: `app/[lang]/404/page.tsx` → `out/{lang}/404.html`, Apache показывает её для отсутствующих адресов под `/{lang}/`; `app/global-not-found.tsx` (`experimental.globalNotFound`) → `out/404.html`, английская, для остального. Глобальная рендерится без layout, поэтому сама подключает шрифт и стили. Разметка обеих — `_components/not-found-view.tsx`: камера над пустой тарелкой, «Блюдо не найдено»; серверная, только CSS-анимации; `noindex`.
- `app/_i18n/`:
  - `config.ts` — языки, язык по умолчанию, названия, форматы, имя cookie языка, `languageAlternates` для `hreflang`;
  - `dictionaries/ru.ts` — тексты интерфейса и **тип `Dictionary`**; `en.ts`, `uk.ts` обязаны ему соответствовать — TypeScript не даст забыть перевод;
  - `i18n-provider.tsx` — `useI18n()` в клиентских компонентах: `t`, `locale`, `formatNumber`. Серверный код берёт словарь через `getDictionary(locale)`;
  - `legal/` — политика и условия отдельным файлом на язык (`privacy.en.tsx` и т. д.), `index.ts` собирает их по языкам;
  - `seo.ts` — `pageMetadata()`: title, description, canonical, `hreflang`, Open Graph и Twitter для страницы на одном языке.

**SEO**

- Каждая страница получает метаданные через `pageMetadata()`; тексты — `meta` в словарях.
- `app/[lang]/og.png/route.tsx` — картинка для соцсетей `/{lang}/og.png` (1200×630, собирается при сборке), подключается в `pageMetadata()` с подписью на языке страницы. Обычный маршрут, а не `opengraph-image`: у того в статическом экспорте не работает `generateImageMetadata`. Шрифт — `assets/fonts/` (Commissioner TTF, OFL, из пакета `@expo-google-fonts/commissioner` мобильного проекта): шрифт `next/og` по умолчанию без кириллицы. Знак — `appMarkSvg()` из `_components/app-mark.tsx`.
- `app/sitemap.ts` — все языковые версии со ссылками друг на друга; `app/robots.ts`; `app/manifest.ts`; иконки — из `npm run icons`.
- **Новая страница:** маршрут в `app/[lang]/…`, метаданные через `pageMetadata()`, тексты во все три словаря, адрес в `PAGES` в `sitemap.ts`.

**Компоненты** (`app/_components/`)

- `hero.tsx` — заголовок, телефон с демо камеры, карточки блюд вокруг (от `xl`); `FitPhone` подгоняет макет телефона под высоту экрана на мобильных;
- `scan-demo.tsx` — экран камеры в цикле: наводка фокуса, луч, вспышка, карточка с калориями и БЖУ;
- `how-it-works.tsx` — закреплённый телефон, три экрана сменяются по скроллу; фон `Backdrop` меняет цвет по шагу;
- `day-timeline.tsx` — лента дня, «стакан», совет ИИ с кнопкой добавления;
- `plan-calculator.tsx` — интерактивный расчёт нормы;
- `final-cta.tsx`, `nav.tsx`, `footer.tsx`, `store-buttons.tsx`, `lang-switch.tsx` (меню языков в шапке; в футере — список языков);
- `analytics-consent.tsx` — баннер согласия на cookie и Google Analytics (в `[lang]/layout.tsx`); повторно открывается ссылкой «Настройки cookie» в футере;
- примитивы: `app-mark` (знак «Эквалайзер БЖУ» и искра), `phone-frame`, `glass-meter`, `food-thumb`, `flair-text` (заголовок с «линзой» по осям шрифта), `count-up`, `magnetic`, `velocity-marquee`, `scroll-progress`, `smooth-scroll`.

**Данные** (`app/_lib/`)

- `content.ts` — блюда с фото и БЖУ (названия — в словарях, `t.meals[dish]`), день для таймлайна, дневная норма, ссылки на сторы;
- `nutrition-plan.ts` — расчёт нормы, **копия формул приложения** (`../aifitplus/src/utils/nutrition-plan.ts`): при изменении там — менять здесь;
- `legal.ts` — реквизиты и параметры юридических страниц;
- `photo.ts` — адреса фото Unsplash;
- `analytics.ts` — ID Google Analytics (`G-LN3E8J2156`), хост, ключ согласия.

**Прочее**

- `docs/store-name-reservation.md` — регистрация аккаунтов Apple и Google Play для ФОП и резерв названия.
- `docs/deploy.md` — настройка хостинга (сайт, SSL, SSH-ключ) и деплой.
- `public/*.svg` (кроме `public/icons/`) — остатки шаблона Create Next App, не используются.

## Дизайн

- Палитра — из приложения (`../aifitplus/src/theme/theme.ts`, направление «Вечерний таймлайн»), токены в `globals.css`: `ink` `#12162B` (фон), `surface*`, `line`, `text*`. Смысл цветов как в приложении: `apricot` — действия, съеденное, углеводы; `lilac` — всё про ИИ, жиры; `mint` — белки, прогресс, подтверждения; `rose` — перебор. Новые цвета — токеном в `@theme`, не хексом в разметке (исключение — картинки соцсетей и иконки, где CSS-переменных нет).
- Анимаций много (так просил владелец), но каждая показывает механику продукта: сканирование, распознавание, БЖУ, наполнение «стакана». Декоративных эффектов «ради эффекта» не добавлять.
- «Уменьшение движения» соблюдается: `MotionConfig reducedMotion="user"`, Lenis отключается, CSS-анимации гасятся в `globals.css`.
- Макеты телефонов свёрстаны в фиксированных пикселях (`PhoneFrame` 290×619). Размер менять только масштабом (`transform: scale`, `FitPhone`), не шириной — иначе поедет вёрстка экранов внутри.
- Мобильный hero помещается в один экран: заголовок, телефон, компактные кнопки сторов; плашка «ИИ», подзаголовок и подсказка «Листайте» скрыты до `lg`. В шапке на телефонах — короткая подпись кнопки (`nav.ctaShort`) и переключатель без иконки глобуса.
- Заголовок hero на десктопе ограничен 72px: при большем размере английский и украинский варианты переносятся в 4 строки. Менять размер — проверять все три языка.
- В демо телефона в hero — фото, выбранные владельцем: сырники, боул с тофу, йогурт с малиной. Калории блюд в `content.ts` согласованы с БЖУ (≈ 4·Б + 9·Ж + 4·У).
- Favicon и иконки — знак приложения на тёмном скруглённом квадрате, та же геометрия, что в `../aifitplus/scripts/build-icons.mjs`.

## Языки

- Никакого текста в разметке: всё через словари (`t.…`), даже `aria-label`. Новая строка — сразу во все три словаря.
- Английский — британский, как в приложении (`../aifitplus/src/i18n/locales/en.ts`); русский — из `../aifitplus/src/i18n/locales/ru.ts`. Украинского в приложении пока нет — `uk.ts` сайта можно брать за основу.
- Числа — `formatNumber` или `CountUp` (формат языка: `2,200` / `2 200`), даты — `Intl.DateTimeFormat` с `LOCALE_META[locale].intl`.
- Ссылки внутри сайта — с префиксом языка: `/${locale}/privacy`. Переключатель языка сохраняет текущую страницу и запоминает выбор в cookie.
- SEO-тексты — `meta` в словарях: заголовок до ~60 символов, описание до ~160. Описание страниц политики и условий тоже там (`privacyDescription`, `termsDescription`), не в файлах документов.
- Переводы (особенно юридические) сделаны без носителя и юриста — перед релизом показать носителям украинского и английского.

## Аналитика

- Google Analytics 4 загружается **только после «Принять»** в баннере (базовый Consent Mode: до согласия в Google не уходит ничего) и только на `aifitplus.com` — в `next dev` и `preview:static` её нет. Рекламные сигналы (`ad_*`) выключены. Выбор — в `localStorage` (`aifit-analytics-consent`); отзыв ставит флаг отключения GA и удаляет cookie `_ga*`.
- Сниппет из интерфейса GA в HTML не вставлять — он ставит cookie без согласия.
- Проверка установки в интерфейсе GA пишет «тег Google не обнаружен» — это ожидаемо: тега нет в HTML до согласия. Проверять так: на живом сайте нажать «Принять» → в GA «Отчёты → В режиме реального времени»; или в браузере `performance.getEntriesByType('resource')` — должны быть `gtag/js?id=G-LN3E8J2156` и `google-analytics.com/g/collect` (журнал сети панели браузера сторонние запросы не показывает). Работа на живом сайте проверена 1 октября 2026.
- Владельцу рекомендовано в GA: срок хранения данных 2 месяца (как в политике), «Сигналы Google» выключены, в расширенной статистике включены изменения страницы по событиям истории браузера (иначе переходы без перезагрузки не считаются). Сделано ли — не подтверждено.
- Что собирает GA, описано в политике (раздел `data` → «Сайт», `purposes`, `processors`, `transfer`) на трёх языках: cookie `_ga` до 2 лет, подробные данные 2 месяца (срок хранения по умолчанию в GA), без рекламных функций. Поменяли настройки GA или добавили события — обновить политику.

## Юридическое

- Политика и условия написаны по фактической работе приложения: Supabase (Ирландия), Anthropic (распознавание), Resend, RevenueCat, Apple и Google. При изменении обработки данных в приложении — обновлять политику **на всех трёх языках** (`app/_i18n/legal/`), структура разделов (`id`) одинаковая.
- Незаполненные реквизиты в `_lib/legal.ts` равны `null` и показываются на странице подсвеченной меткой. Страна применимого права (`governingLaw`) задаётся отдельно для каждого языка — у неё разные падежи и написание. Дата вступления в силу — ISO, на странице форматируется под язык. Возраст (`minAge`, 16) и срок хранения резервных копий (`backupRetentionDays`, 30 — зависит от тарифа Supabase) поставлены по умолчанию, владелец их не подтверждал. Личные данные владельца (ФИО, номер в реестре, адрес) не подставлять без его подтверждения.
- Согласие на обработку данных о здоровье — «явное» (ст. 9(2)(a) GDPR), не «письменное».
- Тексты — черновик, не проверены юристом. Открыто: представитель в ЕС по ст. 27 GDPR, уведомление Уполномоченного ВРУ об обработке данных о здоровье, страна применимого права в условиях.
- В мобильном приложении ссылки на документы ведут на `aifitplus.app` (`../aifitplus/src/constants/links.ts`), а сайт — `aifitplus.com/{язык}/privacy|terms`. Нужно поправить в приложении.

## Открытые вопросы

- Название: в сторах уже есть «AiFit: Easy Calorie Counter» (Traffic Heroes Ltd, с января 2025, та же функция); в ЕС и Великобритании знака AIFIT для софта нет. Владелец решает, оставлять ли AIFit+.
- Фото грузятся с `images.unsplash.com` (сайт и картинка соцсетей при сборке); для продакшена — перенести в `public/` (скачивать только с разрешения владельца).

## Проверка

- Смотреть в браузере минимум на 375×812, 360×740, 768×1024 и 1440×900, на всех трёх языках (`/en`, `/uk`, `/ru`) — длина текстов разная; проверять, что нет горизонтального скролла (`document.documentElement.scrollWidth === innerWidth`).
- Редиректы и 404 — на `npm run preview:static`, `curl` с заголовком `Accept-Language` и cookie `NEXT_LOCALE`; у 404 — код ответа и `<html lang>`. Список проверок — в `docs/deploy.md`.
- Если dev-сервер не отвечает (`curl localhost:3002` → `000`), запускать через превью (`preview_start` с `web`). Переходить между `127.0.0.1:8088` и `localhost:3002` через `navigate`, не через `location.href` — иначе вкладка остаётся пустой.
- Если панель браузера скрыта, `requestAnimationFrame` в ней не идёт: анимации Motion «застывают» на первом кадре (в том числе появление меню языков). Это не баг страницы — делать скриншот или проверять состояние через JS.
